# Software Enterprise Website with SaaS

This project is a website for a software enterprise, including a landing page for company introduction and an integrated SaaS platform.

## Project Structure

-  `/client`: Contains the React + Ant Design frontend application.
-  `/server`: Contains the Node.js + Express + MySQL backend application.

## Technology Stack

-  **Frontend:** React, Ant Design, React Router
-  **Backend:** Node.js, Express
-  **Database:** MySQL (or PostgreSQL as an alternative)

## Getting Started

### Prerequisites

-  Node.js (v18 or higher recommended)
-  npm or yarn
-  MySQL (or PostgreSQL) database running

### Installation & Running Locally

1. **Clone the repository:**

   ```bash
   git clone <repository-url>
   cd <project-directory>
   ```

2. **Backend Setup:**

   ```bash
   cd server
   npm install
   # Configure database connection in server.js or via .env file
   # (Create a .env file based on a .env.example if provided)
   npm run dev # Starts the backend server (usually on port 3001)
   ```

3. **Frontend Setup:**

   ```bash
   cd ../client
   npm install
   npm start # Starts the frontend development server (usually on port 3000)
   ```

4. Open your browser and navigate to `http://localhost:3000`.

## Deployment (AWS EC2 - Free Tier Considerations)

1. **EC2 Instance:** Launch a free-tier eligible EC2 instance (e.g., t2.micro or t3.micro) with a suitable Linux distribution (e.g., Ubuntu).
2. **Database:**
   -  **AWS RDS Free Tier:** Use the AWS RDS free tier for MySQL or PostgreSQL. This is recommended for easier management and scalability.
   -  **Install on EC2:** Alternatively, install MySQL/PostgreSQL directly on the EC2 instance (ensure security groups allow access).
3. **Node.js & npm:** Install Node.js and npm on the EC2 instance.
4. **Clone Code:** Clone the project repository onto the instance.
5. **Backend:**
   -  Configure environment variables (database credentials, etc.).
   -  Install dependencies (`npm install`).
   -  Use a process manager like `pm2` to run the Node.js server (`npm install pm2 -g`, `pm2 start server.js`).
6. **Frontend:**
   -  Build the React app: `cd client && npm run build`.
   -  Configure a web server (like Nginx or Apache) on the EC2 instance to serve the static files from the `client/build` directory.
   -  Configure the web server to proxy API requests (e.g., `/api/*`) to the backend Node.js application (running on `http://localhost:3001` or its configured port).
7. **Security Groups:** Configure AWS Security Groups to allow incoming traffic on necessary ports (e.g., 80 for HTTP, 443 for HTTPS, potentially 3001 if accessing the backend directly, and the database port if connecting remotely).
8. **Domain & HTTPS:** (Optional, but recommended) Configure a domain name and set up HTTPS using Let's Encrypt (Certbot) with Nginx/Apache.

**Note on Free Tier:** Be mindful of free tier limits (compute hours, data transfer, RDS usage). Monitor your usage in the AWS console. Using RDS might exceed free tier if usage is high or runs for extended periods beyond the initial free tier duration.
