# WisCreation 网站调整方案 B：内容重组，AI 优先

> 日期：2026-06-07
> 状态：设计方案（未实施）

## 概述

将 WisCreation 企业网站的核心业务定位从 **SaaS** 迁移至 **AI 应用开发**，通过内容重组（而非代码架构变更）实现品牌叙事转型。SaaS 能力降级为 AI 应用交付体系下的支撑能力。

## 与方案 A 的区别

| 维度 | 方案 A（已实施） | 方案 B（本文档） |
|------|-----------------|-----------------|
| 改动范围 | 仅替换 SaaS 相关文案 | 内容层次重组 + 文案替换 |
| 页面结构 | 不变 | Services 页面重组卡片顺序 |
| AI 叙事深度 | 表层替换 | 主线叙事，贯穿全部页面 |
| 案例研究 | 保留 | 替换为 AI 项目案例 |
| 发展历程 | 修改 1 处 | 补充 AI 转型里程碑 |
| 工作量 | 小 | 中 |

## 核心策略

### 1. 叙事层次重组

```
原结构:
  ┌─ 企业网站 → SaaS → ASN.1 Codec
  └─ 服务: 定制开发 | SaaS | 移动 | 安全

新结构:
  ┌─ AI 应用开发（核心） → AI 产品试用（ASN.1 Codec）
  ├─ 支撑能力: 定制开发 · 云服务 · 安全
  └─ 企业背景: AI 驱动转型的故事
```

### 2. 首页（Home）调整

**轮播图重构：**
- 第一张：AI 应用开发主视觉（标题/副标题改为 AI 叙事）
- 第二张：原 SaaS 轮播 → 改为 "AI 应用快速体验"，指向 ASN.1 Codec 试用

**服务特点区域：**
- 三张卡片文案同步调整，SaaS 卡片改为 "AI 应用服务"
- 图标/颜色保持不变

### 3. 服务页（Services）调整

**核心变化：**
- 页面副标题：改为 AI 优先表述
- 主要服务卡片中，"SaaS服务" → "AI 应用服务"
- 专业领域部分的 AI/ML 区块从第三位提升至 隐含优先级（通过文案强化）
- 云解决方案特征列表中的 "SaaS产品开发" → "AI 应用开发"

**案例研究替换（可选）：**
- Case 1 → "基于 LLM 的智能客服系统"
- Case 2 → "RAG 企业知识库平台"
- Case 3 → "AI Agent 自动化工作流"

### 4. 关于我们（About）调整

- 公司简介：强调 AI 应用开发方向
- 使命/愿景：AI 驱动为核心
- 发展历程：
  - Milestone 5：SaaS 平台 → AI 应用平台
  - 可新增 Milestone：AI 转型节点
- 核心价值观保持不变

### 5. 导航 & Footer

- "SaaS应用" → "AI 应用"（保持指向 `/apps/asn1codec`）
- Footer 副标题同步更新
- 控制台标题："SaaS控制台" → "AI 控制台"

### 6. ASN.1 Codec 应用的重新定位

不修改代码功能，仅重新包装入口文案：
- "ASN.1 Codec 演示操场" → "AI 开发者工具箱"
- 入口描述从 SaaS 工具 → AI 互操作性工具

### 7. 多语言同步

zh / en / ja / zh-TW / ko 五个语言文件同步调整，各语言文案保持一致的 AI 叙事方向。

## 不涉及的部分

- 页面路由结构不变
- 组件逻辑不变
- 后端 API 不变
- ASN.1 Codec 应用代码不变
- 认证/登录/注册流程不变
- Dashboard/Project/Task 等内部功能不变

## 实施步骤（如需执行）

1. 修改 5 个 `translation.json` 文件（zh, en, ja, zh-TW, ko）
2. 更新 README.md
3. 更新 Header.js（导航标签依赖 i18n）
4. 编译验证
5. 提交 Git

## 回退方案

由于方案 A 仅涉及文案替换且独立于组件逻辑，可通过 `git revert` 完全回退，或通过 Git 切换分支切换新旧版本。
